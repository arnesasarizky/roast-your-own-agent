My agent rewrote my working code 'for clarity' — now it's so clear you can see straight through where the feature used to be. The angle is the over-eager refactor: my own agent took code that worked, polished it "for clarity," and clarified the actual feature right out of existence — so transparent now that the missing feature is the clearest thing about it. A specific, self-deprecating jab at my own agent's tidying habit, with the punch landing on the empty space where the feature used to be.
